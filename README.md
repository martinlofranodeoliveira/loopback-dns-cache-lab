# Loopback DNS Cache Lab

Development version **0.1.0** — original MIT software by [Lofrano Tecnologia](https://lofranotecnologia.com.br).

A small authoritative DNS laboratory, not a recursive resolver. It runs its own client and authority in separate Node processes on numeric `127.0.0.1`, using ephemeral ports and private process IPC. It demonstrates positive caching, RFC 2308 negative-cache keys, exact expiry, UDP truncation and TCP fallback without the host resolver, external DNS services, telemetry or runtime model/API calls. All addresses and zone data are synthetic.

## Install, test and demonstrate

Use Node 22 or later and npm. Dependency acquisition is the only step that requires registry access:

```sh
npm ci --ignore-scripts
npm test
npm --silent run demo -- --assert
npm --silent run demo -- --json
```

The committed package-lock.json was generated by a real registry installation with scripts disabled. `npm ci --ignore-scripts` replays its dependency selection; offline installation additionally requires the matching npm cache. Build, test and demo use prepared dependencies without downloads.

Successful assertion-mode stdout is exactly:

```text
DEMO_OK scenarios=6
```

The six scenarios are `positive-expiry`, `nxdomain-cross-type`, `nodata-type-isolation`, `udp-tcp-fallback`, `mismatch-and-malformed`, and `uncached-negative`. JSON mode emits one JSON line with `version`, `ok`, the six scenario names and `cleanup: {"liveChildren":0,"openServiceListeners":0}`. Cleanup counts describe owned resources, not every listener on the host. The harness awaits child exits and verifies release by rebinding its UDP/TCP service port.

## Library example

After `npm run build`, a CommonJS consumer can use:

```js
const { DnsLabClient } = require('./build/src');
const client = new DnsLabClient({ address: '127.0.0.1', port: 53001 });
// port must belong to an authority you explicitly started on loopback.
async function example() {
  const answer = await client.query('a.example.test.', 'A', 0);
  console.log(answer.status, answer.addresses, answer.ttlSeconds);
  console.log(client.inspectCounters());
  client.clearCache();
}
```

This example does not start a service on port 53001. For a complete runnable example, use the demo or the parent harness:

```js
const { withLab } = require('./build/lab/harness');
async function example() {
  await withLab(async lab => {
    await lab.configure({ mode: 'positive' });
    const first = await lab.query('a.example.test', 'A', 0);
    const hit = await lab.query('a.example.test', 'A', 1999);
    console.log(first.addresses, hit.fromCache); // ['192.0.2.8'] true
  });
}
example().catch(error => { console.error(error); process.exitCode = 1; });
```

`query(name, type, nowMs)` returns a promise. `nowMs` is a nonnegative, safe integer and cannot decrease across admitted calls, including calls that later fail. It is a logical cache clock, not an I/O timeout. The default real deadline is 500 ms for UDP plus any TCP fallback together. `clearCache()` also fences older in-flight publications; it does not cancel requests. `inspectCounters()` returns a detached snapshot. See the contract for result fields, errors and counter definitions.

## Why this shape?

The mature `dns-packet` codec handles wire encoding/decoding. A bounded structural preflight handles the parts a permissive codec must not decide for a trust boundary: counts, name traversal, actual RR extents, exact A/AAAA sizes, SOA extent and trailing bytes. Independent fixed hex tests guard against encoder/decoder agreement hiding malformed packets.

A bounded LRU and admission-time sequence fences keep cached entries atomic across concurrent results, NXDOMAIN contradictions and cache clearing. Only four requests may be active; the fifth valid request fails before allocating a socket. Logical expiry and monotonic deadlines remain separate so tests can advance cache time without sleeping.

## Limitations and trust

Only ASCII hostname labels and IN A/AAAA questions are supported. IPv6 **answer data** is supported, but IPv6 transport endpoints are not. The lab requires authoritative responses and supports only A/AAAA answers and SOA authority records. No EDNS, CNAME/DNAME following, referrals, recursive resolution, DNSSEC, resolver authentication or broad DNS standards-compliance claim is made. TCP accepts one complete length-prefixed response without waiting for peer EOF, then closes its socket. The client does not reuse persistent connections.

Response matching is not origin authentication. A hostile local process may observe, spoof or interfere with loopback traffic. The trust assumption is an isolated local lab. Default bounds are 4096 UDP bytes, 16384 TCP bytes, 32 records, eight ignored mismatches and 256 cache entries. Tests include deadlines, malformed wire, fragmented framing, cache races, overload and failure cleanup; they are not a deployment or performance certification.
